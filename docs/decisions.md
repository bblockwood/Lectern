# Decisions

Record of spec ambiguities and how they were resolved. Newest at the bottom.

| Date | Topic | Decision | Status |
|---|---|---|---|
| 2026-10-25 | Deployment targets | macOS 26.0, iOS/iPadOS 26.0, watchOS 26.0: the installed Simulator runtimes are 26.5 and the spec allows raising freely. | Fable, provisional |
| 2026-10-25 | Bundle identifier prefix | `dev.lectern` (spikes use `dev.lectern.spike.*`). Ben can change it once signing is set up; nothing depends on it. | Fable, provisional |
| 2026-10-25 | Spike projects | Each spike is a self-contained XcodeGen project or SwiftPM package under `Spikes/`, not a target of the main project, so M0 code can be deleted without touching `project.yml`. | Fable |
| 2026-10-25 | Frame grouping in second-screen-notes decks | Beamer's page labels equal frame numbers in ordinary decks (verified on `overlays.pdf`) but **not** when `show notes on second screen` is used (`notes-right.pdf`: 5 frames, labels 1,1,2,2,3,3). M3 needs a different grouping signal for notes-split decks. Options to evaluate then: the frame number printed on the slide, beamer's `Navigation<n>` named destinations, or treating each page as its own frame. | Open, for M3 |
| 2026-10-25 | Render engine | `CGContext.drawPDFPage` is fast enough (≤ 18 ms at 4K on the heaviest fixture, ~3 ms typical) and skips annotations by construction. No PDFium evaluation unless real decks show fidelity bugs. See `docs/spikes/C-render.md`. | Fable |
| 2026-10-25 | Concurrent rendering | `RenderCache` serialises renders on one `CGPDFDocument`. The spike showed 4× scaling from sharing the document across threads without crashing, but Apple does not document that as safe, and serial rendering is fast enough. Revisit only if M1 profiling shows queueing. | Fable |
| 2026-10-25 | PresenterCore imports | PresenterCore also imports `os` (for `os_log`/`os_signpost`, which CLAUDE.md asks for) and the repo's own `PresenterProtocol`, which defines `Command` so remotes and the core share one type. No UI frameworks. | Fable |
| 2026-10-25 | Mac app sandbox | Not sandboxed in M1 (hardened runtime on). Live reload needs to watch the deck's directory and read `.pdfpc`/`.pptx` siblings (§6.6, §5.1), which the sandbox makes awkward; personal/TestFlight distribution does not require it. Revisit for the App Store in M10. | Fable, provisional |
| 2026-10-25 | Cache eviction policy | `ImageStore` evicts the entry farthest from the focus pages (committed, presenter, back target) first and least-recently-used among equals, instead of pure LRU: in the self-test LRU evicted the page the presenter was about to go back to. Mac budget 768 MB (`-cacheMB=` to override); iPad will use less. | Fable |
| 2026-10-25 | Pace thresholds (§6.7) | Behind by up to 60 s is green, up to 180 s amber, beyond that red, computed as (elapsed/target − framesDone/framesTotal) × target. Section targets (M6) will refine this. | Fable, provisional |
| 2026-10-25 | Key handling | One `NSEvent` local monitor feeds `KeyMap` for every window, so clicker keys work regardless of which window is key, and the audience window never becomes key. Unmodified single-key shortcuts are therefore not menu key equivalents; menu titles show them. Text fields (M2 jump field, M3 notes editor) bypass the map. | Fable |
| 2026-10-25 | Latency measurement | `-selftest` reports input → event receipt → command applied → layer contents swapped, plus the first display-link vsync after the swap as an on-glass upper bound. The render server's compositing stage is not observable from the app; the built-in ProMotion panel also idles at low refresh rates, so only a fixed-rate external display gives a clean "one refresh" number. | Fable |
| 2026-10-25 | Focus prompt | The one-time "enable a Focus" prompt from §6.1 is deferred to M10. | Fable, provisional |
| 2026-10-25 | Overview selection granularity | Arrow keys and clicks in the overview browse to the **first** page of a frame (unbuilt), while thumbnails show the frame's last page as §4.1 asks. Committing then presents the frame from its first build. | Fable, provisional |
| 2026-10-25 | GoForward | Beamer's navigation bar emits the GoForward named action; the session keeps a `forwardHistory` stack (filled by `back`, cleared by any new jump) so it works. No key is bound to it. | Fable |
| 2026-10-25 | URI links | Ignored with a two-second notice. `defaults write dev.lectern.mac LecternOpenURILinks -bool YES` enables opening them after a confirmation dialog on the presenter Mac (SPEC §4.3, §13 open question). | Fable, provisional |
| 2026-10-25 | Thumbnail cache | A second `RenderCache` with a 96 MB budget renders the last page of each frame at up to 640×360; the overview re-requests on demand after eviction. | Fable |
